🏥 PrendreSoin Chat - Démo Iframe

Simulation d'intégration du chatbot dans un site externe

ℹ️ À propos de cette démo

Cette page simule l'intégration du chatbot PrendreSoin dans un site web tiers via une iframe. Les liens dans les messages du chatbot s'ouvriront dans la fenêtre parente grâce à target="_parent".

💡 Astuce: Ouvrez les outils de développement pour inspecter l'iframe et son contenu. Les liens cliqués dans le chat s'ouvriront dans cette fenêtre parent.
